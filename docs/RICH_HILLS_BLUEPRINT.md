# Rich Hills Blueprint

Status: planning blueprint, not runtime code  
Scope: hillside geography, roads, civic systems, housing, academy, police/private security, jobs, luxury economy, minigames, marina, assets, and build phases  
Project: Zaylin's Kid World, also called ZTA

**Rich Hills** is ZTA's wealth, property, negotiation, hospitality, and status town. It should feel aspirational without pretending that a functioning luxury district contains only mansions. Rich Hills needs estates, condos, a marina, country club, luxury shopping, private clinic, police, private security, academy, service workers, affordable employee housing, fuel, repairs, sanitation, delivery access, and ordinary residents.

Players can move here for high-paying service work, property progression, business education, luxury vehicles, golf, marina life, and premium homes. They can also experience stricter trespassing rules, faster patrol response, higher fines, private gates, and social-status consequences.

---

## 1. Design north star

Rich Hills should feel:

```txt
sunlit hills
cream stone
terracotta roofs
dark green landscaping
gold and brass details
curving roads
country club quiet
marina sparkle
polished but lived-in
wealth supported by visible workers and systems
```

Avoid:

```txt
only giant empty mansions
copying real luxury brands
making every NPC rude or shallow
hiding all worker housing outside the map
unreadable gated property boundaries
security that punishes players before warning them
one flat road with houses pasted beside it
```

Core fantasy:

```txt
Work your way in, learn how wealth systems work, buy property,
collect vehicles, build status, run services, or simply live well.
Rich Hills rewards money and skill, but it also watches you closely.
```

### Road hierarchy

| Road | Tier | Function |
|---|---|---|
| Grand Boulevard | main | Starter Town gateway and central spine |
| Crest Avenue | main | Civic Crest and Tech tunnel |
| Estate Ridge Drive | curved local/main | uphill mansion route |
| Mansion Loop North/South | local | gated residential loops |
| Country Club Drive | local/special | clubhouse/golf circulation |
| Marina Boulevard | main/curved | waterfront connection |
| Service Road | service | deliveries, sanitation, fuel, repair |
| Garden Way | local | public park and housing |
| Tech Tunnel Approach | tunnel/main | connection to TechTown |

### Intersections

- Grand Boulevard x Luxury Row: full traffic light
- Grand Boulevard x Marina Boulevard: full traffic light
- Grand Boulevard x Crest Avenue: landscaped roundabout or major signal
- Academy zone: raised crosswalk and school signals
- Country Club valet circle: yield controls
- Mansion loops: gates and stop signs
- Service Road: truck markings and stop signs

### Transit

- RichLine shuttle between Grand Entry, Civic Crest, Country Club, Marina, and worker housing
- fast-travel node at Civic Crest
- valet/taxi drop zones
- player cars and boats supported

### Traffic behavior

- lower congestion than Starter Town
- more luxury vehicles
- service traffic concentrated in mornings/service roads
- police/private security patrol density higher
- speeding enforcement stronger near academy and estates

## 14. Police, private security, and crime

### Authority model

- Rich Hills Police Department handles public law
- estate/private security handles gated properties first
- country club and marina security handle their facilities
- police response is faster than Starter Town, especially near estates, academy, luxury dealership, and marina

### Local crimes

| Action | Consequence |
|---|---|
| Trespass gated estate | rapid warning/security response |
| Steal luxury car | tracker response, high fine, wanted heat |
| Damage valet vehicle | restitution, job ban, heat if intentional |
| Steal art/jewelry | security lock, evidence, high wanted level |
| Break into marina/yacht | marina ban, patrol response |
| Fake club/member pass | removal and temporary ban |
| Vandalize golf course | repair/community groundskeeping task |
| Scam property buyer | reputation/business access loss |
| Enter private clinic restricted area | security/police response |
| Tamper with CrestFuel/service keys | fast camera/security response |

### Response modifiers

```txt
Public Service Village: normal response.
Academy: faster response to dangerous driving.
Luxury Row: high camera coverage.
Country Club/Marina: private security first, police backup.
Estate Ridge: highest patrol density and fastest response.
```

### Clearing trouble

- pay higher local fine
- return stolen property/vehicle
- complete groundskeeping/community task
- repair damaged vehicle/property
- wait out club/marina/job ban
- take property ethics class
- rebuild business/status reputation

## 21. Completion checklist

Rich Hills is not complete until the player can:

- arrive from Starter Town and navigate curved hill roads
- reach TechTown tunnel
- buy affordable, mid-tier, marina, and premium homes
- attend Legacy Preparatory Academy
- work at least six local jobs
- play golf, yacht, valet, car-show, property, and auction loops
- use police, private security, clinic, fire/rescue, fuel, food, repair, and transit
- encounter faster response in rich/restricted areas
- understand public versus private property
- live here without needing Starter Town for essentials
- revisit for property, vehicles, marina, high-pay work, education, and status

Final identity:

```txt
Rich Hills is not wealth as decoration.
It is a complete economy of property, service, education, recreation, labor, and stricter consequence.
```
