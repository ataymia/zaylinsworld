# Casino Strip Blueprint

Status: planning blueprint, not runtime code  
Alias: Casino / Vegas Town  
Scope: strip layout, hotels, game halls, arcade systems, civic services, housing, school, police/security, jobs, minigames, economy, assets, and build phases  
Project: Zaylin's Kid World, also called ZTA

**Casino Strip** is ZTA's luck, probability, hospitality, arcade, hotel, spectacle, and entertainment-economy city. It must remain unmistakably fictional and kid-safe. Its casinos are bright game halls using in-world chips/tokens earned or purchased with gameplay currency only. There are no real-money purchases, adult vice systems, or realistic predatory lending loops.

The Strip must function as a city, not a single row of gambling machines. It needs hotels, apartments, schools, police, casino security, restaurants, clinics, fuel, transit, maintenance, sanitation, show venues, arcades, ordinary jobs, and neighborhoods for the people who work there.

---

## 1. Design north star

Casino Strip should feel:

```txt
neon boulevard
large themed game halls
hotel towers
arcade energy
crowds and spectacle
controlled chaos
luck mixed with skill and hospitality
bright public front + complex service back
```

Avoid:

```txt
real-money gambling presentation
adult clubs or alcohol-driven identity
loan-shark realism
one endless room of slot machines
copied casino brands or famous landmarks
unlimited payouts that destroy the economy
making every activity pure luck
hiding workers, housing, and maintenance
```

Core fantasy:

```txt
Arrive for the lights. Stay for the games, shows, hotels, jobs, and city life.
Learn odds, manage risk, master arcade skills, work hospitality,
or become a high-status game-hall regular without using real money.
```

### Intersections

- Gateway Road x Main Strip: signature traffic light/arch
- Main Strip x Civic Way: signalized with police/academy visibility
- Main Strip x Arcade Avenue: signalized and pedestrian-heavy
- Main Strip x Hotel Loop: signalized/drop-lane control
- Studio Boulevard north gate: traffic light and directional signage
- service road: stop signs/loading controls

### Transit

- Strip Transit Terminal as fast-travel hub
- shuttle loop between gateway, plaza, hotels, arcade, academy, and Starline gate
- parking garages reduce curb clutter
- hotel taxis/rideshare lanes
- player cars supported throughout public roads

### Pedestrian flow

- busiest: Neon Plaza, Main Strip, Arcade Avenue, hotel lobbies
- moderate: academy and residential park
- restricted: service roads, game-hall back rooms, security operations
- skywalks only where they improve routing rather than decorate empty air

## 14. Police, casino security, and crime

### Authority model

- public roads: Casino Strip Police Department
- game halls: venue security first
- hotels: hotel security first
- arcade: arcade staff/security
- service quarter: operations security/cameras

### Local crimes

| Action | Consequence |
|---|---|
| Cheat game minigame | station ban, token freeze, security response |
| Steal chips/tickets | confiscation, venue ban, heat |
| Enter VIP/restricted area | escort, escalating heat |
| Steal hotel-room item | hotel ban and police response |
| Tamper with arcade cabinet | repair fine/job ban |
| Fake event/room pass | removal and access suspension |
| Steal service vehicle | standard wanted system |
| Damage neon/sign equipment | repair/community shift |
| Tamper with LuckyLine/token card | quick camera response |
| Refuse legitimate hotel/service bill | service lockout/fine, no predatory debt system |

### Response behavior

- highest security density inside game halls/hotels
- camera detection common
- police patrol Main Strip and Gateway
- residential response normal
- service alleys monitored but less crowded
- cheating consequences focus on bans/frozen local tokens rather than endless chases

### Clearing trouble

- pay fine
- return chips/tickets/items
- complete repair/community shift
- wait out venue ban
- attend responsible-play/security class
- restore venue reputation through legal jobs

## 21. Completion checklist

Casino Strip is not complete until the player can:

- enter by harbor bridge and leave toward Starline City
- navigate Main Strip, service road, residential, academy, hotel, and arcade districts
- buy basic and premium housing
- attend BrightHouse Institute
