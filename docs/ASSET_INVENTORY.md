## What the findings mean

### Runtime integrity

All indexed runtime assets exist. Starter Town is not failing because the asset index points at missing models.

The 254 unindexed files are mainly kit-library models that are discovered through kit-specific indexes rather than `asset-index-v2.json`. They are not automatic deletion candidates.

### Chicken Spot fryer assets

The requested dedicated fryer files are **not present** in the runtime model library:

- `prop_deep_fryer_single_v01.glb`
- `prop_deep_fryer_double_v01.glb`
- `prop_fryer_basket_empty_v01.glb`
- `prop_fryer_basket_chicken_v01.glb`

- `prop_heat_lamp_food_warmer_v01.glb`

Starter Town therefore uses a lightweight procedural stainless fryer line until dedicated licensed assets are added. Oven and burner-stove pieces are excluded from Chicken Spot so the kitchen does not read like a bakery or pizza restaurant.

## Cleanup policy

1. No runtime asset is deleted without a reference search.
2. Missing indexed files are blockers; there are currently none.
3. Unindexed kit files are classified before routing or removal.
4. Duplicate-content files remain until manifests and kit indexes are updated together.
5. Oversized assets are optimization candidates, not deletion candidates.
6. License, credit, texture, `.bin`, and source-companion files remain attached to their assets.
7. Initial loading stays incremental. Optimization must not restore all-at-once preloading.
